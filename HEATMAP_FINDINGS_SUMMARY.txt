1. NO DEDICATED HEATMAP CODE

2. COLORMAP VISUALIZATION EXISTS
   The repository contains colormap-based visualization in these files:

   a) demos/VFRRT/plotConservative.py (Line 58)
      - 3D surface plot with cm.coolwarm colormap

   b) demos/KinematicChainPathPlot.py (Lines 72-74)
      - Uses viridis colormap
      - Shows robot pose evolution over time
      
   c) demos/DubinsAirplanePlot.py (Line 48+)
      - Uses tab10 colormap
      - Distinguishes trajectory components

================================================================================
CONCLUSION
================================================================================

OMPL is a motion planning library focused on algorithms, not visualization.
While it has some colormap-based plotting for demonstrations and benchmarks,
it does not contain traditional heatmap functionality.

The closest to a "heatmap" is the 3D surface plot in plotConservative.py
which uses color gradients to represent values across a 2D grid.
